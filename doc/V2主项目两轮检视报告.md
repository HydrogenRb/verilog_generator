## 第一轮：需求实现与针对性检视

| 检视点 | 结果 | 证据/处理 |
|---|---|---|
| TOP 3 项、CORE 3 项、MEM 2 项的模板展开 | 通过 | `aligned_expansions()` 按 provenance 取值并集对齐；只存在于 TOP/CORE 的 `sig3` 仍正常连接，差异为 info |
| 所有 parameter 上游可配 | 通过 | 子模块独有 parameter 提升为 TOP parameter；同名参数统一传入 TOP 名称，不生成 localparam |
| parameter 位宽差异 | 通过 | 不报“位宽不匹配”，由 elaboration 使用统一 TOP parameter 解析 |
| 宏冲突 | 通过 | `APB_1=4/3` 输出 warning，按 TOP→CORE→MEM 顺序保留上层值 `4`；子模块文件不重复 define |

| 旧格式/条件/数组/interface | 通过 | 主单元测试 35/35；Tech Review 1 矩阵 6/6 |

第一轮发现并修正了两个回归审计脚本的 V1 假设：“wire 按驱动端位宽”和“子模块参数必须是 localparam”。另将 Tech Review 2 样例 warning 数量同步到当前用户修订的 `test.xlsx`。
