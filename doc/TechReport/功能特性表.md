# XLSX → Verilog 功能特性表

本文档是 V3.45 的功能索引。行为细节、输入示例和排错方法见根目录[`README.md`](../../README.md)，内部实现入口见[代码结构与维护指南](代码结构与维护指南.md)，底层位宽裁决矩阵见[《V3.2 位宽不匹配分析》](V3.2位宽不匹配分析.md)。

## 0. 发布演示 Excel 清单

下表覆盖所有需要在 Excel 中主动填写的用户功能。每行都可直接拆成一个演示页签或一条集成连接；“`|`”表示相邻单元格，不是写进单元格的字符。运行、文件保护和诊断等无需 Excel 输入的能力，仍在后续章节逐项列出。

| 特性 | 特性描述 | Excel 最小示例 | 预期结果 |
|---|---|---|---|
| 标量端口 | 位宽空白或 1 | `clk | 1 | 1 | i` | `input wire clk` |
| 固定向量 | 数字表示 packed 总位宽 | `data | 8 | 8 | o` | `output wire [8 -1:0] data` |
| 零位宽保留 | 显式 0 不阻止生成，但提示人工裁决 | `empty | 0 | 0 | o` | `[0 -1:0] empty`及`W_ZERO_WIDTH` |
| 宏位宽 | 反引号名称作为一维宽度 | ``data | `DW | 32 | i`` | ``[`DW -1:0]``及宏参考注释 |
| 宏定义分类 | 只登记宏匹配值以便集中维护和扩散 | `宏定义 | dataWidth | | 32` | 记录`` `dataWidth=32``，不生成端口或活动 define |
| parameter 位宽 | 普通符号作为本模块参数 | `data | DW | 32 | i` | `localparam DW = 32`及`[DW -1:0]` |
| 参数表达式 | parameter 分类可直接生成宏/参数/函数表达式 | ``parameter | DW | `log2(PARA_B) | 3`` | ``localparam DW = `log2(PARA_B) // 3`` |
| 零值 parameter | 参数匹配值允许 0 | `parameter | OPTION_W | | 0` | `localparam OPTION_W = 0` |
| 行级停用 | 备注含`*注释*`时整行不参与模型 | 任意端口/连接行备注`待处理 *注释*` | 不生成该行并记录`I_ROW_COMMENTED` |
| 安全算术宽度 | 外层括号把乘法解释为算术 | `flat | (3*5) | | i` | `[15 -1:0] flat` |
| 多维 packed | 顶层星号拆分维度 | ``matrix | `LANES*DW | 4*8 | i`` | ``[`LANES -1:0][DW -1:0] matrix`` |
| 数组列 | `数组`是位宽外侧 packed 维度 | `data | DW | 8 | i | DEPTH | 4` | `[DEPTH -1:0][DW -1:0] data` |
| interface | `类型.modport`配`i/o=NA` | `chi_if | sky_if.mst | | NA` | `sky_if.mst chi_if` |
| 空方向 | 空 i/o 暂按 inout 保留 | `pad | 1 | 1 | ` | `inout pad`、warning 和 TODO |
| 重复端口 | 同页同名多行合并 | 两行均为`irq | 1 | 1 | i` | 模块只声明一次`irq` |
| 分类继承 | 合并分类单元格向下继承 | 首行分类`APB`，后续分类留空 | 端口统一位于 APB 注释组 |
| 条件分类 | 分类可携带条件宏 | `CFG 条件：FEATURE_CFG` | 开关启用时生成`` `ifdef FEATURE_CFG`` |
| 忽略修改列 | 表头`修改/修改列`整列不参与解析 | `修改`列填写任意审阅文字 | 生成结果不受影响 |
| 单变量模板 | 名称和宽度可使用同名模板变量 | ``bus_{{i}} | `DW_{{i}}``，备注`i={a,b}` | `bus_a/b`与`` `DW_A/B`` |
| 数字范围模板 | 闭区间代替长列表 | `port_{{z}}`，备注`z=0:31` | 展开 32 个端口 |
| 多变量模板 | 不同变量取笛卡尔积 | `bus_{{i}}_{{j}}`，`i={a,b};j={0,1}` | 展开 4 个端口 |
| 模板集合差异 | 模块间可只共享部分取值 | A:`i={a,b}`，B:`i={b,c}` | `b`连接，`a/c`按单端处理并 info |
| 自动集成发现 | 页签名使用`集成`或`集成_xxx` | `集成_riscv_top` | 单候选自动选，多候选可选 |
| TOP↔子模块 | 第一连接区同行表示连接 | `TOP.sig | o || CHILD.sig | i` | TOP 信号驱动子模块 input |
| 子模块互连 | 后续区两个真实端点创建 wire | `SRC.dat | o || SINK.dat | i` | 创建`w_dat`并连接两实例 |
| 单端未连接 | 后续区只有一个真实端点 | `CHILD.req | i` | input 接零；output/inout 开路 |
| 普通 NA | 单真实端对端写 NA | `CHILD.req | i || NA` | 创建同形状占位 wire和 TODO |
| 命名 NA | 指定占位 wire 名 | `CHILD.req | i || NA->req_probe` | 创建同形状`wire req_probe` |
| TOP 命名观察 | 第一连接区支持命名观察 | `TOP.status | o || NA->status_probe` | 创建同形状观察 wire |
| NA 全零/全一 | 0/1按目标全部维度复制 | `TOP.mask | o || NA->1`，宽度 8 | `assign mask = {8{1'b1}}` |
| NA 定宽常量 | 常量与目标总 packed 位宽比较 | `TOP.mask | o || NA->8'hFF`，宽度 16 | `{{8{1'b0}}, 8'hFF}` |
| NA 常量过宽 | 保留常量并提示连接截断 | `TOP.mask | o || NA->8'hFF`，宽度 4 | `W_NA_CONSTANT_WIDTH` |
| NA generate | NA 也可带实例索引 | `CHILD.req[i] | i || NA[i]` | 创建实例循环及额外最左维度 |
| TOP bit select | 显式选择单 bit 连接 | `TOP.n_rst[0] || CHILD.rst_n` | `.rst_n(n_rst[0])` |
| 自动 generate | TOP 引用末尾`[i]`触发实例循环 | `TOP.bus[i] || CHILD.bus` | 按首维安全次数例化 |
| 自定义实例 | 空白区三列表设置名称和次数 | `CHILD | U_SPECIAL | 5` | 实例名`U_SPECIAL`、例化 5 次 |
| 符号例化次数 | 例化次数可使用 TOP parameter 或宏 | `CHILD | U_LANE | LANE_NUM` | 循环上限及`NA[i]`外层维度均使用`LANE_NUM` |
| 参数链接 | 集成分类`parameter`连接各模块参数 | `TOP.DW || CHILD.DW` | 子模块变`parameter`并在`#()`传递 |
| 数字/宏直接传参 | parameter 的集成`i/o`可写自然数或反引号宏 | CHILD.LANE_NUM 的 i/o 写`` `LANES`` | ``#(.LANE_NUM(`LANES))`` |
| parameter NA | 非 TOP parameter 端点可写`NA->A`、`NA[i]->B`或`NA->514` | 在 TOP 正文创建 localparam 并用于实例传参 | i/o 是初始化数据，可与 TOP parameter 端点共存；不一致的多个非空来源才报错 |
| 未链接宽度 parameter | 子模块端口位宽 parameter 未在集成 parameter 行上拉 | TOP 正文创建带子模块数值默认值的 localparam，并同步实例传参 | 不扩大 TOP 外部 parameter 接口；已有同名同值 TOP 参数时复用 |
| 固定宽度适配 | 可解析宽度不等时低位截断/高位补零 | TOP 8 bit 连接 CHILD 4 bit input | `.port(top_sig[4 -1:0])`及 warning |
| 宏冲突拒绝 | 同层同名宏默认值必须一致 | A:`\`DW=8`，B:`\`DW=16` | error，禁止写文件 |
| 修改值扩散 | CLI 按变量统一更新默认值 | `--spread-value DW 32` | 确认后更新关联数值并备份 XLSX |

## 1. 运行、输入与输出

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| 零第三方依赖 | 只使用 Python 3.10+ 标准库读取、修改 XLSX 并生成 Verilog | 不依赖`openpyxl`，可离线运行 |
| XLSX 读取 | 直接读取 OOXML ZIP、workbook relationships、shared strings 和 worksheet cells | 不计算 Excel 公式，也不保留完整样式模型 |
| 输出文件 | 每个参与当前层次的模块生成一个`.v` | 文件名小写；文件内模块名保持大写 |
| 编码与换行 | UTF-8、LF | 通过临时文件原子替换同名目标 |
| 输出目录保护 | 只更新本次目标模块对应文件 | 不删除目录内其他文件 |
| 返回码 | 成功为`0`，校验/生成失败为`2`，交互中断为`130` | strict warning 也返回`2` |
| 启动标识 | 直接运行时输出对齐的脚本名、V3.45、日期和联系方式 | 主生成器与独立 merger 使用相同版本号 |
| 可配置文件头 | 明文多行配置生成到每个`.v`开头 | 默认作为 USER 段保留；可开启覆盖 |
| SystemVerilog | 支持多维 packed、interface、`'0`和 generate | 虽使用`.v`扩展名，相关工具需启用 SystemVerilog 模式 |

## 2. 模块页签与表头

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| 表头定位 | 在页签前 20 行按名称识别字段，不依赖固定坐标 | 基础必需表头为`端口名/位宽/数值/i/o` |
| 表头别名 | 支持中英文 width/value/direction/array 相关别名 | 具体别名以 README 表格和解析器 alias 集合为准 |
| 模块名 | 取`端口名`上方同列最近的非空值，支持`module:`/`module：`前缀 | 找不到时使用页签名 |
| 分类继承 | 合并单元格首行分类可向后续空分类行继承 | 无分类使用`no group` |
| 重复端口 | 同一模块同名端口合并为一个物理端口 | 冲突属性产生诊断 |
| 修改列 | 名为`修改`或`修改列`的整列在任何业务解析前移除 | 模板、方向、分类、集成和扩散都不会读取该列 |
| 信号大小写 | 普通信号、端口、模板来源和模板值严格保留大小写 | `Data`与`data`视为不同信号 |
| 规范化名称 | 模块、parameter 转为大写，文件名转小写 | 普通宏保持用户输入；只有模板宏展开后大写；端口和自定义实例名不改大小写 |
| `*注释*`行 | 备注命中标记后整行结构化停用 | 模块端口、宏/parameter 和集成连接统一生效 |
| `*注释*`模块 | 集成子模块标签写`module:CHILD *注释*`时注释完整实例 | 其他解析、连线和子模块文件生成不变；TOP 不允许停用 |
| 标签例化名 | 写`module:CHILD 例化名:U_CHILD_A`指定实例名 | 优先于元数据表；同一 module 可用不同标签名生成多个独立实例 |

## 3. 方向、声明与占位逻辑

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| input/output | 生成`input wire`/`output wire` | 所有普通内部声明也固定为`wire` |
| inout | 生成`inout [range] name` | 按项目格式不追加`wire` |
| 空 i/o | 暂按`inout`生成，同时输出 warning 和代码 TODO | 需要人工确认真实方向 |
| interface 方向 | 位宽为`interface_type.modport`时，`NA/N/A/interface`表示 interface | 不生成 interface 类型定义 |
| 模块 output 桩 | 普通模块的每个 output 自动赋零 | 标量使用定宽零，多维 packed 使用`'0` |
| TOP output 兜底 | 没有活动子模块驱动时自动赋零 | 条件化驱动存在时只在驱动关闭的配置兜底 |
| 内部声明类型 | 普通内部网络、位宽适配网络、NA 占位全部为`wire` | 当前生成器不生成`reg`声明 |
| 中文注释 | 内部 wire、位宽适配、TOP 兜底和模块桩均带中英文说明 | NA 实例连接附加中文 TODO |

## 4. 位宽、数组与表达式

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| 数字位宽 | `N`生成`[N -1:0]`，`1`生成标量；显式`0`保留为`[0 -1:0]` | 零位宽输出`W_ZERO_WIDTH`，数字、宏、parameter 在同维左对齐 |
| 宏位宽 | `` `Width``生成注释参考``// `define`` | 匹配默认值允许 `0`；不主动定义；普通宏大小写保持用户输入 |
| 宏定义分类 | `macro/macros/宏/宏定义`登记宏和值 | 元数据专用，不生成端口、parameter 或活动`` `define``；参与冲突检查与扩散 |
| parameter 位宽 | `WIDTH`默认生成模块`localparam` | 匹配默认值允许 `0`；不再生成`integer`，默认不允许上层覆盖 |
| 显式 parameter 分类 | `parameter/parameters/参数/参数定义`分类声明参数 | `位宽=`安全单行 Verilog 生成表达式，支持宏/宏调用/其他 parameter/系统函数/运算；`数值=`独立匹配值和注释，可为 `0` |
| 安全整数表达式 | 支持括号、`+ - * / // % << >> & | ^` | 不执行名称、函数或任意 Python 代码 |
| 多维分隔 | 顶层`*`表示维度分隔，空格不改变含义 | 算术乘法必须放在整体括号内 |
| XLSX 数组字段 | `数组`及其别名表示外层维度，`数组数值`提供默认值 | 模型为兼容 API 仍单独保存，生成时转为 packed |
| 维度统一在左侧 | 普通信号按“数组维度 → 位宽前置维度 → 最终元素位宽”生成 | 例如`数组=DEPTH, 位宽=DATA_W`生成`[DEPTH][DATA_W] sig` |
| 右侧维度 | 普通 input/output/inout/wire 名称右侧不生成范围 | interface 实例数组受语法限制，是唯一保留的右侧维度例外 |
| 多维接零 | 未连接 input 和桩 output 使用整信号`'0` | 不再为数组清零生成 generate-for |
| 形状比较 | 比较 interface 基础类型及全部维度 | 含 parameter 的维度交给 elaboration，不做固定切片 |
| 不确定模板宽度 | warning 后使用`114`作为显式待确认值 | 普通非模板符号最终仍无默认值时为 error |

## 5. 模板展开

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| 任意模板变量 | 支持`{{i}}`、`{{j}}`、`{{z}}`等合法变量名 | 不再限定单个固定 token |
| 列表取值 | 支持`i是{a,b}`、`i={a,b}`、`i in {a,b}`等写法 | 同分类可继承取值 |
| 数字范围 | `z=0:31`和`z=31:0`按闭区间展开 | 单范围最多 4096 项 |
| 多变量模板 | 同一端口多个变量按笛卡尔积展开 | 变量按名称绑定，不互相借用列表 |
| 多字段模板 | 端口名、位宽、默认值和数组字段均可引用模板 | 只有含模板 token 的宏在完全展开后大写；信号名保留模板值大小写 |
| 花括号修复 | 可恢复的`{j}}`或`{{j}`按`{{j}}`处理并 warning | XLSX 源文件仍应修正 |
| provenance 对齐 | 集成连接按来源模板和展开值逐项匹配 | 不会把普通`data_debug`误匹配成`data_{{i}}`展开项 |
| 展开集合不同 | 按取值并集连接已有端点，缺失项按单端/未连接处理 | 记录 info，不因数量不同直接中止 |

## 6. 集成页签与层次选择

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| 自动发现 | 优先识别`集成`、`集成_xxx`及英文兼容名 | 无命名候选时回退到结构识别 |
| 结构识别 | 同一表头行至少有两组`端口名/i/o`模块块 | 模块块之间按空列划分连接区 |
| 漏写重复表头 | 有合法模块名和端口数据时可恢复后续模块块 | 方向改由模块定义校验并记录 info |
| 单集成页签 | 自动使用，不显示额外选择 | 名称可以是`集成`或`集成_xxx` |
| 多集成页签 | 终端菜单选择；CLI 使用`--integration SHEET` | 一次只生成所选层次及其模块 |
| 第一连接区 | 第一块为 TOP，后续块为子模块，同一行表示 TOP↔子模块 | TOP input 不能由子模块 output 反向驱动 |
| 后续多模块区 | 同一行生成子模块内部网络 | 唯一 output 为驱动端；多 output 报 error |
| 后续单模块区 | 解释为显式未连接端口 | input 接零，output/inout 使用空连接 |
| 完全遗漏端口 | 自动按未连接处理并记录 info | 保证实例 named-port 列表确定且完整 |
| 参数连接行 | 连接区分类写`parameter`后按参数而非端口解析 | 显式链接可由实例覆盖；V3.45 未链接宽度 parameter 另有正文局部化路径 |
| 子模块参数互连 | 没有 TOP 端点时自动创建 TOP `localparam` | 输出 info；参数名冲突时自动唯一化 |
| parameter 来源追踪 | macro 保持全局宏；TOP parameter 来源使用 TOP 名；TOP 宏表达式下钻为宏；数字来源创建子模块参数同名正文 localparam | 内部 wire、NA wire 和空连接零值共用映射，不把 wire 固化成数字 |
| 实例元数据表 | 可选`模块名/例化名/例化次数`三列 | 次数接受正整数、TOP parameter 或宏；缺列时保持`U_<MODULE>`及自动次数 |

## 7. NA、观察端口与 generate

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| 普通`NA/N/A` | 内部连接只有一个真实端时创建同形状 wire 占位 | 实例连接追加`//TODO:本信号期望有逻辑功能，请完成` |
| `NA[i]` | 为真实端模块注册 generate，新增最左侧 packed 循环维并连接`placeholder[i]` | interface 不支持该形式 |
| `NA->名称` | 创建使用指定合法标识符的占位 wire | 重名或非法名为 error |
| `NA->0/1` | input 直接连接复制式；TOP output 生成 assign | 按所有 packed 维度生成`{A*B{1'b0/1}}`；output 子模块端开路 |
| 零值统一 | 空 input、TOP 兜底、桩 output 与`NA->0`共用完整形状复制式 | 静态零维使用`'0`，避免零次复制兼容问题 |
| `NA->定宽常量` | 计算源常量和目标 packed 总位宽 | 源较窄显式高位补零；源较宽保留原式并输出`W_NA_CONSTANT_WIDTH` |
| 匿名 NA 列 | NA 端可以不写模块名，也可以省略自己的`端口名/i/o`表头 | 必须紧跟正常列对，且所有非空值只能是 NA 形式 |
| TOP 观察端口 | 第一连接区中 TOP 真实端口的对端可以写 NA | 保留 TOP 端口，不查询`模块.NA`；无驱动 output 赋零 |
| TOP 命名 NA | 第一连接区支持`NA->signame` | 创建同形状观察 wire并生成`assign signame = top_port`及 TODO；interface 除外 |
| 后续连接区统一 | 单真实端点无 NA 时接零/开路，有 NA 时创建占位；多真实端点互连 | 单模块和多模块不再走两套处理分支 |
| `[i]`实例标记 | 端口引用末尾的符号索引触发对应子模块 generate | 生成索引改名为独立`i_gen_<实例名>` |
| generate 次数 | 显式正整数/parameter/宏优先，否则从最左维度取安全最小值 | 符号原样进入循环和 NA 外层维度；无法推导时使用 1 |
| 自定义实例名 | 元数据表中的名称直接用于实例和 generate block | 默认仍为`U_<MODULE>` |
| 常量 bit select | TOP 端口可写`signal[0]`等固定索引 | 仅支持安全的单维 packed 普通端口，并检查越界 |

## 8. 位宽裁决与连接诊断

| 功能 | 当前行为 | 备注/边界 |
|---|---|---|
| 方向校验 | 集成`i/o`与模块定义逐端口比较 | 空集成方向采用模块定义并记录 info |
| 固定宽度不匹配 | 输出 warning，并在安全时低位截断或高位补零 | 显式 bit select 优先，不再自动改写 |
| 内部 wire 宽度 | 可确定时取所有端点最大宽度，并优先保留来源宏/parameter 表达式 | 子模块 parameter 未链接时创建正文 localparam，并输出`W_PARAMETER_AUTO_LOCAL` |
| parameter 维度 | 不做固定宽度不匹配和切片 | 由 SystemVerilog elaboration 裁决 |
| 多维/interface 适配 | 仅在语义可确定时直接连接 | 不安全时保留形状诊断供人工处理 |
| 零位宽 | 允许生成并输出`W_ZERO_WIDTH` | 不参与最大宽度、切片和补零计算；Verilog 没有可移植的零宽 net |
| NA 常量位宽 | 定宽常量较窄时补零，较宽时 warning | 目标维度不可解析时保留原式并提示人工确认 |
| 无驱动内部网络 | 生成 wire 并赋`'0` | interface 网络除外 |
| 多驱动 | 内部多个 output 为 error；TOP output 多个子模块驱动产生 warning | 条件配置会参与驱动兜底判断 |
| 宏冲突 | 同一层次同名宏默认值不同为 error | 诊断列出页签和各自数值 |
| parameter 差异 | 未显式链接时各模块保持自己的 local 值 | 显式链接后以 TOP localparam覆盖并记录 info |

## 12. 当前明确限制

| 限制 | 说明 |
|---|---|
| interface 定义 | 生成器只引用 interface/modport，不生成类型本身 |
| interface 数组位置 | SystemVerilog interface 实例数组只能保留在名称右侧，不适用普通信号“维度全左”规则 |
| 公式求值 | 不运行 Excel，也不读取外部公式计算引擎；输入应提供可见单元格值 |
| 模板范围上限 | 单个数字闭区间最多 4096 项 |
| generate 回退 | 没有显式符号次数且索引范围完全不可解析时只生成 1 次并 warning |
| 显式例化次数 | 超过可解析索引范围只 warning，不自动截断用户指定次数 |
| 零位宽语言语义 | `[0 -1:0]`用于保留 Excel 原始规格并定位问题，不是跨工具可移植的零宽声明；下游编译前需人工处理 warning |
| TOP interface 命名 NA | 普通 TOP 端口支持`NA->名称`观察 wire，interface 不支持该连续赋值别名 | 使用普通信号或在 USER CODE 中实现项目专用 interface 观察逻辑 |
| RTL 语义完成度 | NA、桩 output、自动置零是可审查占位，不替代项目真实逻辑 |
| 编译模式 | 多维 packed 和 interface 需要 SystemVerilog 模式 |
