当我运行代码之后的小菜单可以选择扩散变量值，扩散变量值允许批量修改变量的数值，我进入这个模式之后，脚本会先检测是否有大问题，然后一开始选择对应的宏或parameter，然后输入对应的数值，excel表格中对应位置的数值将会变成我设置的值（这暗示了一次只能修改一个，而非多个）

# 位宽扩散规则
1. 在某一个模块中有相同名字的宏或参数，其中一个或多个有数值，数值一样；同时有一些使用这个宏或者参数的地方留空了，其他的直接使用这个宏或变量，而不报error。
2. 上层模块有这个参数或者宏，下层模块可以直接使用这个参数或者宏的数值，而不需要人手动标注
3. 在某一个模块中有相同名字的宏或参数，其中有不同数值，报error
4. 上层模块和下层模块使用了相同名字的参数，其中有不同数值，top应该在例化的时候overwrite
5. 上层模块和下层模块使用了相同名字的宏，其中有不同数值，报error

# 修改
1.assign已经向左靠齐，声明module的部分也应该向左靠齐
```verilog
assign a;
PHY_SUB U_PHY_SUB(//这一行没有空格
    input xxx;//这只有4个空格
) 
```
2.模型的名字应该是英文大写字母；页签和module名不限制大小写；总结是在excel中放宽大小写限制，在生成Verilog的时候只有信号是小写，例化的时候用大写，模块也用大写
3.目前，所有乘法已经被统一成多维数组有三种情况（彻底弃用 * 的判断标准，不看*前后的空格）
| 位宽 | 数值 | 生成结果 |
|---|---|---|
| LANE_NUM*LANE_W | 3*5 | 生成多维数组 |
| LANE_NUM*LANE_W | 15 | *的数量不匹配，报错 |
| LANE_NUM*LANE_W | (1+2)*5 | 生成多维数组 |
| LANE_NUM | 3*5 | 报错 |
| LANE_NUM | (3*5) | 生成信号，位宽15 |

4.目前无论生成啥，在-1:0之前都应该有一个空格，这样gvim才能搜索到
5.请考虑数组赋值给一个数的情况，你应该关注review2case的dft_test_en这个信号，较多数值进入top，这种时候应该给子模块赋值低位，比如.dft_test_en(dft_test_en[0])，剩下的部分输入悬空，输出赋0
6.考虑到generate的情况，[i]方括号是指示符，比如对于TOP的信号
```verilog
input [BUS_IN -1:0] bus_in;
output [BUS_OUT_DAT -1:0][DW -1:0][BUS -1:0] dyadic_bus_out_dat; //这里有多个output，但是我只展示了一个
```
我们因为使用了[i]会在top生成generate模块
```verilog
//伪代码
//略过声明i的部分
generate for (i=0; i<5;i=i+1) begin
    MEM_DAT U_MEM_DAT(
        .bus_in(bus_in[i]),
        .dyadic_bus_out_dat(dyadic_bus_out_dat[i]))
    ;
end
```
请注意，如果能解析出for循环的次数，则解析之后输出一个info，如果不能解析，则报warning，并且在for循环中默认为<1
7.对于使用模板展开的情况，我们要在对应的数值写“范围是{1,2,3}”这样声明展开的那一块的具体数值，具体可以参考review2case的dyadic_bus_out_{{z}}信号
