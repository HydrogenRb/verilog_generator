# NA逻辑的细化
NA之后可以加入的东西有这几种
- NA->sig_name    生成对应数量的wire信号，自动计算信号形状和大小
- NA->`1          生成对应数量的1或者0，形如{32{1'b1}}
- NA->8'hFF       计算位宽，如果小于，则顶补0，如果大于，报warning，并且指出其错误

# 对于0位宽的支持
我们需要成功生成0位宽而不报错，可以有warning，但是需要至少能生成。
