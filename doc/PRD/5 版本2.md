# 当前项目修改点
1.必须适配展开之后不一致的情况，比如5条线进入top，2条进入子模块A，2条进入子模块B，1条在top模块本地处理（在当前情况下是悬空）；为了做到这样我生成了09_version_2作为测试。
2.使用参数作为模块位宽的时候，我们应该不管位宽的冲突，因为参数应该作为module一开始申明的，可以被上级例化的时候覆盖。请你让每一个参数都可以被上级修改（声明成parameter），如果top有这个位宽，则让上级赋值下去，而非“参数不同”
3.对于宏，如果上级定义了，则下面不要定义；如果上下数值有冲突，则报warning并且按照上级的生成。
4.对于用模板生成的，。
5.对于位宽不匹配的情况，请你生成这种逻辑
```verilog
wire [10:0] sig1; //在top中按照较大的生成
MODULE_A U_MODULE_A (.sig1(sig1)); //一个信号输入给他
MODULE_B U_MODULE_B (.sig1(sig1[0])); //信号的低位给他
assign sig1[10:1] = '0; //赋0或者悬空，按照规则处理
//这个地方记得报一个warning
```
5.5.对于上面的总结：如果参数都存在（同名）但是不匹配（比如114和1）；则使用top的；如果宏在上下都存在的数值不匹配，则不使用下级的数值那一栏，使用上级的并且报一个warning；如果无论如何都冲突，则按照规则5处理；你在生成的过程中应该考虑到不同情况
6.对于自动按未连接端口处理应该报info（因为有很多内部数据）。
