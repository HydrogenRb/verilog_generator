# 新功能
加入一个新的config位，名字是ONLY_TOP，如果选择了true，那么只生成顶层（也就是集成页签）

# 位宽的匹配
让我们回顾V3.2的位宽矩阵，其中对于任一维是 parameter的情况，你不报warning，但是这种时候请你提出warning，并且有一个config开关能决定是否自动补0；这个warning对于多维也需要支持，特别是可以在多维条件下补0；不要管宏覆盖的事了。

# 宏页签功能
新建一个页签，就叫做define，这个页签可以统一定义宏

# 新的USER CODE
在statement区后面新建usercode段，就叫做after statement

# 功能修改
- generate的索引固定成i而不是gen_i_xxx
- 现在不应该因为NA出现xxx_2这样的信号
- 重复使用target名字不应该出现报错
- 对于自动创建的w_xxx信号，还是允许_2
- 只要是出现在module #()中的代码都要parameter

# 移除功能
变量值扩散的功能没人用，请去掉；
