# 第 13 组生成结果

这些 `.v` 使用 `techreview2version3.xlsx` 的临时副本生成。为保留原始错误路径，源 XLSX 未修改；临时副本仅统一以下四组跨模块宏：

- `` `RST_LANE = 5``
- `` `CLK_LANE = 5``
- `` `APB_1 = 4``
- `` `LANE_NUM = 5``

生成结果用于检视用户代码保护段、`z=0:31`模板范围、`RISCV_CRG`的内部`NA[i]`占位数组和 generate 连接。`CLK_BUS_0`～`CLK_BUS_31`在样例中没有数值，按模板占位规则暂取 114，因此`G_RISCV_CRG`当前循环 114 次；`z=0:31`本身只展开 32 个端口。原始 XLSX 直接运行`--check`应因上述四组宏冲突返回 2，并显示冲突页签和值。
