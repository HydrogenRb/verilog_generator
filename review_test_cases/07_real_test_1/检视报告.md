# Real Test 1：Ibex IF Stage 直接例化 3 个子模块

## 开源项目依据

- 项目：lowRISC Ibex，Apache-2.0。
- 固定版本：`7b5df75a041affe56e8c235260f98a09b3319008`。
- [`ibex_if_stage.sv`](https://github.com/lowRISC/ibex/blob/7b5df75a041affe56e8c235260f98a09b3319008/rtl/ibex_if_stage.sv) 中包含 `ibex_prefetch_buffer`、`ibex_compressed_decoder`，并在 `DummyInstructions` 配置开启时包含 `ibex_dummy_instr`。
- 子模块接口取自同版本的 [`ibex_prefetch_buffer.sv`](https://github.com/lowRISC/ibex/blob/7b5df75a041affe56e8c235260f98a09b3319008/rtl/ibex_prefetch_buffer.sv)、[`ibex_compressed_decoder.sv`](https://github.com/lowRISC/ibex/blob/7b5df75a041affe56e8c235260f98a09b3319008/rtl/ibex_compressed_decoder.sv) 和 [`ibex_dummy_instr.sv`](https://github.com/lowRISC/ibex/blob/7b5df75a041affe56e8c235260f98a09b3319008/rtl/ibex_dummy_instr.sv)。

本测试采用 `ICache=0`、`DummyInstructions=1` 的结构视图，并抽取纯 `logic` 标量/向量接口。没有复制开源项目的功能实现。

## 输入与执行

- 输入：[`ibex_if_stage_3children.xlsx`](./ibex_if_stage_3children.xlsx)
- 输出目录：[`generated`](./generated)
- 独立审计明细：[`audit_result.json`](./audit_result.json)

执行命令：

```powershell
python .\xlsx2verilog.py .\review_test_cases\07_real_test_1\ibex_if_stage_3children.xlsx `
  -o .\review_test_cases\07_real_test_1\generated
```

脚本生成 4 个文件且没有诊断：

- `ibex_if_stage.v`
- `ibex_prefetch_buffer.v`
- `ibex_compressed_decoder.v`
- `ibex_dummy_instr.v`

## 检视结果

独立静态审计共 67 项，全部通过：

- TOP 中三个子模块均只例化一次；
- 每个子模块端口均且仅连接一次；
- 端口声明与 XLSX 去重后的定义完全一致；
- 预取缓冲的 `valid_o` 可同时扇出到 decoder 和 dummy-instruction 模块；
- `rdata_o` 与不同名的 `instr_i` 可通过生成的 32-bit wire 连接；
- 未连接 input 置零，未连接 output 悬空；
- 子模块桩文件中的所有 output 均赋零；
- 模块边界和括号结构完整。

## 能力边界

生成结果是合法的结构骨架，不是 Ibex IF stage 的功能等价替代品：

1. XLSX 能描述端口直连、扇出、置零和悬空，不能描述原模块内部的 mux、流水寄存器、错误组合与 PC 选择逻辑。
2. 原源码中的 `instr_valid_id_o`、`instr_rdata_id_o` 来自 IF/ID 流水寄存器，不是某个子模块的直接 output；当前生成结果只能按规则在 TOP 内置零。
3. `ICache`、`DummyInstructions`、`ResetAll` 等行为参数不属于“端口位宽参数”，现有表格规则无法表达条件 generate。
4. `ibex_pkg` 枚举、结构体、数组端口和 SystemVerilog import 不在当前 XLSX 模型范围内，因此本测试使用了可表达的接口切片。
5. 生成的三个子模块是 output 赋零的桩模块，不包含开源项目的 RTL 行为。

分类结论：未发现脚本在既定规则内的结构生成问题；发现“从连接表生成完整功能 RTL”这一明确能力边界。
