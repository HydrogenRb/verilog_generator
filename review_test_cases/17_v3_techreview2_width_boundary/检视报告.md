# V3.2 位宽边界检视报告

## 用例目的

`width_boundary.xlsx`把位宽裁决集中在一个可重复演示的工作簿中。集成页签为`Integration_WIDTH_REVIEW`，包含 TOP 与子模块连接、后续子模块内部互连、parameter、多维 packed、显式零位宽、命名 NA、0/1 常量和定宽常量。

运行命令：

```powershell
py.exe .\xlsx2verilog.py `
  .\review_test_cases\17_v3_techreview2_width_boundary\width_boundary.xlsx `
  --integration Integration_WIDTH_REVIEW `
  -o .\review_test_cases\17_v3_techreview2_width_boundary\generated
```

预期生成 4 个文件，返回码为 0；因为本样例有意制造 warning，`--strict`预期返回 2。

## 场景与预期

| 场景 | XLSX 端点 | 预期生成行为 |
|---|---|---|
| TOP 8 位驱动 child 4 位 input | `to_narrow → in4` | warning；child 连接 TOP 低 4 位 |
| TOP 4 位驱动 child 8 位 input | `to_wide → in8` | warning；child 连接表达式高 4 位补零 |
| child 4 位 output 驱动 TOP 8 位 output | `from_narrow ← out4` | warning；连接 TOP 低 4 位，TOP 高 4 位补零 |
| child 8 位 output 驱动 TOP 4 位 output | `from_wide ← out8` | warning；创建 8 位 adapter wire，TOP 取低 4 位 |
| parameter 宽度不同 | `P_TOP=8 → P_CHILD=4` | 不做静态 warning/切片，交给 elaboration |
| 多维 packed 形状不同 | `[2][4] → [2][8]` | warning；不做一维切片，保持直接连接 |
| 显式 0 位宽 | `zero_bus` | 生成`[0 -1:0]`和`W_ZERO_WIDTH`，不报 error |
| 定宽常量小于目标 | `NA->8'hFF → const_wide[15:0]` | 生成`{{8{1'b0}}, 8'hFF}` |
| 定宽常量大于目标 | `NA->8'hFF → const_narrow[3:0]` | 保留`8'hFF`，产生`W_NA_CONSTANT_WIDTH`并说明上下文截断风险 |
| 全 1/全 0 | `NA->1/0` | 分别生成`{8{1'b1}}`与`{8{1'b0}}` |
| 命名观察 wire | `probe → NA->probe_alias` | 创建同形状 wire 和带 TODO 的观察 assign |
| 内部 3 位 output 驱动 5 位 input | `src3 → sink5` | 生成 5 位 wire，源连接低 3 位，高 2 位补零 |
| 内部 9 位 output 驱动 2 位 input | `src9 → sink2` | 生成 9 位 wire，sink 连接低 2 位 |
| 内部 parameter/多维 | `param_src/multi_src` | parameter 直接连接；多维不一致 warning 后直接连接 |

## 诊断基线

- `W_ZERO_WIDTH`: 1
- `W_NA_CONSTANT_WIDTH`: 1
- `W_WIDTH_MISMATCH`: 8
- error: 0

对应自动回归位于`tests_script/test_version3_review2.py`。`generated/width_review.v`可直接查看低位截断、高位补零、adapter wire、NA 常量和零位宽声明。
