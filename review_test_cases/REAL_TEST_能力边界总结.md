# Real Test 能力边界总结

本轮以 lowRISC Ibex 固定提交 `7b5df75a041affe56e8c235260f98a09b3319008` 为依据，且没有修改 `xlsx2verilog.py`。

| 案例 | 结构 | 结果 | 结论 |
|---|---|---|---|
| `07_real_test_1` | `ibex_if_stage` 直接例化 3 个子模块 | 生成 4 个文件；67 项审计通过 | 单层多子模块、不同名端口互连和一驱多接收端可用 |
| `08_real_test_2` | `ibex_core` 例化 3 个，其中 `ibex_if_stage` 再例化 3 个 | 两层分别生成；组合后 7 个模块；182 项分层审计与 5 项组合检查通过 | 两级层次可通过多个 XLSX 组合，不能由单个 XLSX 一次完成 |

最主要的边界：

- 一个工作簿只能有一个集成层级；
- 深层模块需要逐层工作簿和外部替换桩文件；
- 连接表不能表达 mux、流水寄存器、算术/控制逻辑和条件 generate；
- 当前端口模型不能保真表达复杂 SystemVerilog package 类型、结构体和数组；
- 所生成文件是结构骨架和接口桩，不是开源 RTL 的功能复刻。

详细证据分别见 [`07_real_test_1/检视报告.md`](./07_real_test_1/检视报告.md) 和 [`08_real_test_2/检视报告.md`](./08_real_test_2/检视报告.md)。
